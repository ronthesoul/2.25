# 2.25 Project Tasks

This repository contains the solutions for tasks 27-35 from the Linux Fundamentals book. These tasks cover various aspects of Linux system administration, and the scripts provided here offer detailed answers and implementations to each task.

## Task Overview

1. **[Task 27](https://github.com/ronthesoul/2.25/blob/test/task_n27.sh)** - User Management
   - Create, modify, and manage users on Linux using commands like `useradd`, `usermod`, `passwd`.
2. **[Task 28](https://github.com/ronthesoul/2.25/blob/test/task_n28.sh)** - User Creation with Specific Attributes
   - Create users with home directories, specific shells, and default files for new users.
3. **[Task 29](https://github.com/ronthesoul/2.25/blob/test/task_n29.sh)** - Password Management
   - Change and enforce password policies using `passwd`, `chpasswd`, and other tools.
4. **[Task 30](https://github.com/ronthesoul/2.25/blob/test/task_n30.sh)** - Profile Management
   - Work with profile files to set environment variables, aliases, and functions for users.
5. **[Task 31](https://github.com/ronthesoul/2.25/blob/test/task_n31.sh)** - Group Management
   - Manage user groups using `groupadd`, `groupmod`, and assign users to groups.
6. **[Task 32](https://github.com/ronthesoul/2.25/blob/test/task_n32.sh)** - Permissions and Ownership
   - Modify file and directory permissions using `chmod`, `chown`, and `umask`.
7. **[Task 33](https://github.com/ronthesoul/2.25/blob/test/task_n33.sh)** - Directory Permissions
   - Set up directories with specific group ownership and permissions, enforcing controlled access.
8. **[Task 35](https://github.com/ronthesoul/2.25/blob/test/task_n35.sh)** - Hard and Symbolic Links
   - Work with hard and symbolic links to manage file relationships.

For details on each task, refer to the corresponding script in the repository.
